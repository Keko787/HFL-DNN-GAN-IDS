# Experiment 4 — pinned environment that produced results/exp4_paper/*.csv
#
# The integrated experiment (arms H0-H3, real DNN-IDS, the crossover surface +
# L1 result) was run on Python 3.11.9 with the versions below — newer than the
# base .venv310 stack in requirements_core.txt (Python 3.10 / tf 2.15 / keras 2).
# The code runs on either; use this file for bit-faithful reproduction of the
# committed exp4 CSVs.
#
# These are the DIRECT third-party dependencies of the exp4 pipeline; pip
# resolves the transitive rest (absl-py, h5py, protobuf, etc.).
#
#   python3.11 -m venv .venv311
#   source .venv311/Scripts/activate      # Git Bash on Windows
#   pip install -r AppSetup/requirements_exp4.txt
#   pip install pytest                    # test runner (markers in pytest.ini)
#
# On Windows, prefer an interpreter that is not a venv for Exp 5: a venv's
# python.exe there is a launcher stub that starts the real interpreter as a
# child, so every trial process appears twice and the Study 5.11 footprint
# probe reads the stub (test_exp5_footprint fails 4 tests). A conda env is the
# interpreter itself:
#
#   conda create -p <env> python==3.11.9
#   <env>\python.exe -m pip install -r AppSetup/requirements_exp4.txt pytest
#
# Data: place CICIOT-2023 at ../datasets/CICIOT2023 or set HERMES_CICIOT_DIR;
# or pass `--data-source synthetic` to run without the dataset.
#
# What each is used for:
#   numpy         - arrays throughout (model_task, channel, stats, analysis, figures)
#   pandas        - analysis/exp4.py + the canonical CICIOT loader
#   scipy         - analysis/stats.py Wilcoxon signed-rank (scipy.stats)
#   scikit-learn  - roc_auc_score (model eval) + train_test_split/scalers (loader)
#   matplotlib    - the rebuttal figures (exp4_figure*.py)
#   tensorflow    - create_CICIOT_Model (Config/modelStructures/NIDS/NIDS_Struct.py)
#   keras         - Keras 3 backend that tf.keras routes to under tensorflow>=2.16
#   psutil        - optional: the footprint probe only (Exp 5 addendum, Study 5.11,
#                   --footprint-probe); nothing else imports it
#   flwr          - not used by exp4, but the canonical loader's preprocess module
#                   (Config/DatasetConfig/Dataset_Preprocessing/datasetPreprocess.py)
#                   imports it at load time, so `--data-source canonical` fails without
#                   it. Added 2026-10-05; it moves protobuf to 6.33.6, inside tensorflow's
#                   range (>=6.31.1,<8). requirements_core.txt's flwr==1.9.0 needs
#                   protobuf<5 and does not fit this stack.
